# Producer Ujay Email Templates

These HTML files are designed for LeadConnector / GoHighLevel email responses:

- `collab-response.html`
- `advertise-response.html`

They use inline CSS and table layout for email-client compatibility.

Before sending live campaigns, update any merge tags if your LeadConnector account uses a different contact token than:

```txt
{{contact.first_name}}
```

The templates use existing hosted Producer Ujay assets, so no image uploads are required.
